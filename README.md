# Sniper 项目环境配置

## 1. 项目概览
1. 通过大恒相机 SDK 采集图像
2. 使用 OpenCV 做预处理
3. 使用 GStreamer 管线编码（x264enc）
4. 通过串口或 MQTT 发送数据

## 2. 依赖与版本

### 2.1 构建层最低要求

- CMake >= 3.16
- GCC/G++ 支持 C++17
- OpenCV
- yaml-cpp
- Protobuf >= 3.19.0
- GStreamer 1.0 + gstreamer-app-1.0
- libmosquitto
- 大恒 Galaxy SDK 运行库

### 2.2 已验证版本

- OS: Ubuntu 22.04.5 LTS
- CMake: 3.22.1
- G++: 11.4.0
- OpenCV: 4.5.4
- yaml-cpp: 0.7.0
- Protobuf: 3.19.3
- GStreamer: 1.20.3
- Mosquitto: 2.0.11
- Daheng SDK

## 3. 一键配置环境

项目根目录提供脚本：`setup_env.sh`

执行：

```bash
cd /path/to/Sniper
bash setup_env.sh
```

**如果有conda环境，需要将anaconda3/bin目录下的protoc可执行文件改名为protoc_**

脚本默认行为：
  如果存在 Conda 安装，会将 `~/anaconda3/bin/protoc` 重命名为 `~/anaconda3/bin/protoc_`，避免污染系统 Protobuf 检测
  检查 Protobuf 版本，自动从源码安装 3.19.3
  检查并验证 GStreamer `x264enc` 插件
  检查 `libgxiapi.so` 是否可用
  自动执行 CMake 配置与编译

### 3.1 可选环境变量

- `SKIP_BUILD=1`：只安装环境，不执行编译
- `PROTOBUF_FORCE_SOURCE=0`：关闭“强制源码安装”，改为按版本检查决定是否源码安装

示例：

```bash
PROTOBUF_FORCE_SOURCE=0 SKIP_BUILD=1 bash setup_env.sh
```

## 4. 手动配置流程

### 4.1 安装系统依赖

```bash
sudo apt update
sudo apt install -y \
  build-essential cmake pkg-config curl ca-certificates tar \
  libopencv-dev libyaml-cpp-dev \
  libprotobuf-dev protobuf-compiler \
  libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev \
  gstreamer1.0-tools gstreamer1.0-plugins-base \
  gstreamer1.0-plugins-good gstreamer1.0-plugins-ugly \
  libmosquitto-dev mosquitto mosquitto-clients
```

说明：Protobuf由脚本默认源码安装为 3.19.3，不建议再通过 apt 安装 `libprotobuf-dev` 和 `protobuf-compiler`，以免版本混用。

### 4.2 检查关键组件

```bash
protoc --version
pkg-config --modversion opencv4
pkg-config --modversion yaml-cpp
pkg-config --modversion gstreamer-1.0
/usr/bin/gst-inspect-1.0 x264enc >/dev/null && echo x264enc_ok
ldconfig -p | grep libgxiapi.so
```

## 5. 运行

在项目根目录编译完成后：

```bash
cd build
./sniper
```

程序默认读取配置：

- 大恒相机：`config/daheng_camera/feature.yaml`
- MQTT：`config/mqtt/server.yaml`
- 串口：`config/serial/serial.yaml`

默认发送链路在 `src/main.cpp` 中设置为 `mqtt`。

## 6. 常见问题

### 6.1 报错：GStreamer element creation failed

通常是缺少 `x264enc` 插件。安装：

```bash
sudo apt install -y gstreamer1.0-plugins-ugly
```

### 6.2 报错：generated by a newer version of protoc

说明 Protobuf 版本过低。需要安装 >= 3.19.0

### 6.3 链接失败：cannot find -lgxiapi

说明大恒 SDK 未正确安装或运行库未进入系统库路径。请先手动安装/配置 Daheng Galaxy SDK，再重新执行脚本.
